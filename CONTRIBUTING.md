# Contributing

Thank you for your interest in contributing to the Simple Interest Calculator project.

All contributions are welcome, including bug reports, bug fixes, documentation improvements, enhancements, and ideas.

## How to Contribute

1. Fork the repository and create a branch for your changes.
2. Make your changes and test them before submitting.
3. Open a pull request with a clear description of your contribution.
4. Be respectful and follow the project's Code of Conduct.
