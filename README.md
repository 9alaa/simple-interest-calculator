# Simple Interest Calculator

A Bash script that calculates simple interest based on user input.

## Description

This project calculates simple interest using three values:
- Principal amount (P)
- Annual interest rate (R)
- Time period in years (T)

## Formula

Simple Interest = (P * R * T) / 100

## How to Run

1. Clone this repository.
2. Open the project folder in your terminal.
3. Run `bash simple-interest.sh`.
4. Enter the principal, annual interest rate, and time period when prompted.
5. View the calculated simple interest.

## Example

Principal: 1000
Rate: 5%
Time: 2 years

Simple Interest = (1000 * 5 * 2) / 100 = 100
